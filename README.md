# Miffy — Bunny AI

Bunny AI is a private personal AI companion: a witty, honest, slightly savage best friend who happens to be a cute bunny. Built with Next.js (App Router), React, strict TypeScript and Tailwind CSS.

## Status

Phase 1–2 complete: project foundation, original SVG bunny avatar with 10 expressions, and the responsive chat UI. There is no AI, database or voice yet; replies arrive in Phase 3.

## Run locally

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
npm run lint
```

Copy `.env.example` to `.env.local` once provider and database keys are needed (never commit it).
